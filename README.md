# 🧮 Calculator Project

A simple calculator web application built using **HTML, CSS, and JavaScript**. This project allows users to perform basic arithmetic calculations through an interactive calculator interface.

## 🌐 Live Website

🔗 [View Live Calculator](https://afnadhossain.github.io/calculator-project/)

## 📸 Project Screenshot

![Calculator Project Screenshot](./assets/project-screenshot.png)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Simple and clean calculator interface
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear button to reset the input
- Equal button to calculate the result
- Interactive buttons using JavaScript
- Displays the entered calculation and result

## 📦 Dependencies

This project does not use any external libraries, frameworks, or packages.

It is built using:

- **HTML5** — for the structure of the calculator
- **CSS3** — for styling and layout
- **JavaScript** — for calculator functionality and user interaction
